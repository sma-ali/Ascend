# Ascend

Suivi calorique qui tient compte de l'entraînement. L'objectif du jour est recalculé
selon les séances, et la composition des produits est visible au moment d'ajouter.

Next 16, React 19, TypeScript, Tailwind. Node 20.9 minimum.

```bash
npm install
npm run dev
```

http://localhost:3000
